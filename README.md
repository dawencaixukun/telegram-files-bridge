# telegram-files-bridge

## 项目简介

telegram-files-bridge 是一个面向 Telegram 媒体收藏者的自托管归档系统。它将媒体下载、云端归档、浏览取回、账号运行和异常保护整合到同一个 Web 管理后台，适合需要长期从 Telegram 频道/群组收集视频等大文件并统一存放到自己网盘的个人用户。

项目采用 Python + Telethon 实现 Telegram MTProto 直连：登录、消息拉取、媒体流式下载均由客户端完成；下载完成的文件自动上传到 OpenList 网盘（OneDrive、Google Drive 等），网页控制台负责任务、库存、归档与账号状态的全流程管理。

## 核心功能

**下载与传输**
- 提交 Telegram 消息链接或频道 + 消息 ID 即可入队，支持批量与多任务并发
- 频道监听：订阅规则开启后新消息实时入库，无需手动翻历史
- 断点续传：大文件取回中断后从已传字节继续，不从头来
- FloodWait 自动冷却与恢复，账号状态页可视化健康度

**归档与管理**
- 下载完成后按目录模板自动上传 OpenList 网盘，同名冲突可选覆盖/跳过/重命名
- 文件名广告自动清洗（Emby / Jellyfin 友好）
- OpenList 改名自愈：网盘里改了文件名，归档链接自动重新定位
- 磁盘高低水位熔断：占用达高水位自动暂停并清理，回落低水位恢复
- 会话备份与恢复：本地快照 + 一键上传云端，快照可手动管理

**Web 管理后台**
- 浏览频道历史媒体，点选取回；云端已归档文件网格展示，一键跳转 OpenList 定位
- 会话侧栏自由管理：隐藏/显示即时生效，收藏置顶不可隐藏
- 任务队列、本地库存、云端归档、日志中心（SSE 实时推送）、账号健康一页全览
- 玻璃拟态深/浅双主题，零构建链（纯 HTML/CSS/JS + htmx + Alpine.js）

## 环境要求

- 可直连 Telegram API 的网络环境
- 一个 OpenList 实例（用于网盘转存）
- Telegram API ID / Hash（[my.telegram.org](https://my.telegram.org) 免费申请）
